# 角色飞书绑定与执行路由（开发中）

依据固定 product-design/c29c2f5 的角色生命周期：飞书可选，首版一个应用关联一个角色；历史 Run 固定角色与渠道配置。工作空间旧连接保留兼容，但不能接管明确选了无渠道或角色专属渠道的执行。

本增量在角色版本内保存不含 Secret 的完整绑定快照，不另建独立可漂移的应用配置权威。角色保存省略渠道字段继承；null 明确不接入；绑定变更生成新的绑定身份和角色版本。应用在历史角色版本中保留归属，禁止给另一角色或旧工作空间连接复用，防止旧卡片和新角色争领同一回调。复制角色不复制渠道授权。Secret 仅由宿主密文引用提供，内核、业务库、事件和普通错误不含明文。

执行创建后按 Run.roleSnapshot 选路；不随角色后续编辑漂移。角色试运行不向飞书投递。每个应用仅建立一条连接，回调必须核对该请求所属 Run 的确切绑定身份、应用、租户、所有者和会话，并调用已有 human.resolve。重复事件、旧请求、过期审批仍受唯一用例和命令回执约束。

通知按绑定身份与 Run 独立记游标，首次正文和 uuid 在网络前冻结，结果未知沿用既有幂等与55分钟边界；不得将另一个执行的正文发送给旧绑定。断开只关闭连接，不删除历史或撤销平台应用。退出需要关闭并等待自有通知请求收敛后才关闭数据库。

迁移只新增路由投影表、提高 schema 门禁，不改写旧角色、Run、任务或事件。旧备份只在副本迁移，源归档不变。旧工作空间渠道只处理缺省渠道字段的旧执行；明确 null 表示无渠道。

专用飞书测试应用尚未创建/连接；“产品经理”仅为已授权模板，不复制其凭证、运行数据或连接现有服务。注册应用须通过官方 SDK device grant，由所有者授权；App ID 参数表示更新已有应用，不应传模板 App ID 来创建副本。不同应用的 open_id 不可直接复制，需分别核验。
