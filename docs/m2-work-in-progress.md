## 第二 CLI 依据

本机 Claude Code 2.1.308 的 --help 与官方资料一致：restricted 模式限制文件工具至工作目录，safe-mode 禁用用户定制，dontAsk 拒绝未预先允许的操作。官方说明原生 Windows 的命令不在 Claude Bash 沙箱中，因此本阶段不开放 Shell。

- [官方 CLI 参数](https://code.claude.com/docs/en/cli-reference)
- [官方权限与工作目录](https://code.claude.com/docs/en/permissions)
- [官方沙箱平台范围](https://code.claude.com/docs/en/sandboxing)

没有把工具权限表述为操作系统容器。实际角色健康仍通过本机试运行验证。
