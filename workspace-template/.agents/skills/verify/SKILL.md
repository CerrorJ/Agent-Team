# Verify

## 执行顺序

1. 从产品文档（云文档或本地 Spec/Tickets）和开发者提供的改动摘要中，提取用户可观察的验收标准，逐条整理成检查清单。
2. 确认应用真实运行中且可访问；无法启动、缺少账号或外部依赖不可用时，停止并明确报告阻塞，不猜测结果。
3. 先运行 `agent-browser skills get core` 读取与已装 CLI 版本匹配的工作流，再按它操作页面；需要系统性探索时加载 `agent-browser skills get dogfood`。
4. 对每条验收标准：在真实页面上执行对应操作，用截图或页面快照留证；只认浏览器里实际发生的行为。
5. 汇总结论：全部通过时直接说明检查通过；有失败时逐条给出验收标准、实际观察、可复现步骤和证据（截图路径）。

## 边界

- 只报告有证据的问题，不代替开发者修改代码，不扩大测试范围。
- 浏览器下载受限的环境，可设置 `AGENT_BROWSER_EXECUTABLE_PATH` 指向本机 Chrome 后直接使用。
- 结论必须区分"验收通过""验收失败"和"环境阻塞"，三者不混用。
